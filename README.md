# LearnMate AI

An AI-powered Study Assistant designed to make learning easier and more accessible for college students.

## Project Overview
LearnMate AI is a web-based application that uses Artificial Intelligence to help students understand topics, summarize study material, and practice through quizzes.

## Features

### 1. Explain
Explains academic topics in simple and easy-to-understand language.

### 2. Summarize
Converts lengthy text into concise summaries containing the key points.

### 3. Quiz Generator
Generates multiple-choice questions based on user-provided topics.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Google Gemini API

## Project Structure
- `app.py` – Flask backend
- `templates/` – HTML frontend pages
- `index.html` – Home page
- `explain.html` – Explanation feature
- `summarize.html` – Summarization feature
- `quiz.html` – Quiz generation feature

## Objective
To develop a student-friendly AI tool that simplifies studying and makes learning more interactive.
